# Najibullah Faqirzada — Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Included features
- Short animated page-opening screen and hero reveal
- Looping, muted typing video in the “Behind the Screen” section
- Responsive navigation and layout for mobile and desktop
- Featured coursework projects with source links
- Skills, About, image gallery, and contact sections
- Reduced-motion support for visitors who prefer less animation

## Run locally
1. Open this folder in Visual Studio Code.
2. Start the Live Server extension from `index.html`.
3. Keep the `images` folder next to `index.html`; the typing video uses `images/typing.mp4`.

## Publish with GitHub Pages
Push the contents of this folder to the intended portfolio repository, then open **Settings → Pages** and select the branch and root folder used by the project. Wait for deployment and test the published URL.
